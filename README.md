# ごみ収集スケジュール管理システム - 設定ガイド

## 📋 概要

このシステムは、通常の曜日ごとの収集と、特殊なスケジュール（金曜日など）を管理できます。

## 🔧 設定方法

### 1. week_list_configurable.js の設定

#### 通常の曜日ごとの収集設定

```javascript
const garbageMaster = {
    0: ["資源", "燃やせる"], // 日曜日
    1: ["燃やせる"],         // 月曜日
    2: ["プラスチック"],     // 火曜日
    3: ["燃やせる"],         // 水曜日
    4: ["資源"],             // 木曜日
    // 5は金曜日（特殊スケジュール）
    6: ["燃やせる"]          // 土曜日
};
```

#### 特殊スケジュールの曜日設定

```javascript
const specialDay = 5; // 金曜日を特殊スケジュールに設定
// 0=日, 1=月, 2=火, 3=水, 4=木, 5=金, 6=土
```

#### 特殊スケジュールの詳細設定

```javascript
const specialSchedule = {
    1: ["資源"],              // 第1週
    2: {
        even: ["埋立"],       // 偶数月の第2週
        odd: ["埋立", "剪定枝"] // 奇数月の第2週
    },
    3: ["資源"],              // 第3週
    4: ["大型", "小型家電", "有害"], // 第4週
    5: ["資源"]               // 第5週
};
```

#### 表示名のカスタマイズ

```javascript
const specialScheduleLabels = {
    1: "資源(第1金曜日)",
    2: {
        even: "埋立(第2金曜日)",
        odd: "埋+剪(奇数月第2金曜)"
    },
    3: "資源(第3金曜日)",
    4: "大、小、有(第4金曜日)",
    5: "資源(第5金曜日)"
};
```

#### 年末年始の休止期間設定

```javascript
const holidayPeriods = [
    { month: 12, dates: [29, 30, 31] },    // 12月29-31日
    { month: 1, dates: [1, 2, 3, 4] }      // 1月1-4日
];
```

### 2. friday_week_list_configurable.js の設定

#### 対象曜日の設定

```javascript
const targetWeekday = 5; // 金曜日
// 他の曜日にも変更可能: 0=日, 1=月, ..., 6=土
```

#### 表示期間の設定

```javascript
const displayDays = 60; // 今日から60日分表示
// 好きな日数に変更可能（例: 30, 90, 120など）
```

#### 週ごとのスケジュール設定

```javascript
const weeklySchedule = {
    1: ["資源"],
    2: {
        even: ["埋立"],
        odd: ["埋立", "剪定枝"]
    },
    3: ["資源"],
    4: ["大型", "小型家電", "有害"],
    5: ["資源"]
};
```

## 🎯 使用例

### 例1: 月曜日を特殊スケジュールに変更

```javascript
// week_list_configurable.js
const specialDay = 1; // 月曜日

const specialSchedule = {
    1: ["ビン・カン"],
    2: ["ペットボトル"],
    3: ["ビン・カン"],
    4: ["古紙"]
};
```

### 例2: シンプルな毎週固定スケジュール

```javascript
// 特殊スケジュールを使わない場合
const garbageMaster = {
    1: ["燃やせる"],
    2: ["プラスチック"],
    3: ["燃やせる"],
    4: ["資源"],
    5: ["燃やせる"],
    6: ["資源"]
};

// specialDayを使用しない（コメントアウト）
// const specialDay = 5;
```

### 例3: 表示期間を3ヶ月に延長

```javascript
// friday_week_list_configurable.js
const displayDays = 90; // 約3ヶ月分
```

## 📌 注意事項

1. **配列のインデックス**: 曜日は0（日曜）から6（土曜）で指定
2. **月の偶数/奇数**: 1月=奇数, 2月=偶数, ..., 12月=偶数
3. **第5週**: 月によっては第5週が存在しない場合があります
4. **HTML要素**: 以下のIDを持つ要素が必要です
   - `schedule-body`: スケジュール表のtbody
   - `friday-list`: 金曜日リストのtbody
   - `today`: 今日の日付表示エリア

## 🚀 カスタマイズのヒント

- ごみの種類は自由に変更可能（例: "燃やせる" → "可燃ごみ"）
- 複数のごみを同じ日に設定可能（例: `["資源", "プラスチック"]`）
- 偶数月/奇数月の分岐は第2週以外にも適用可能
- 年末年始以外の祝日も同様に設定可能

## 💡 トラブルシューティング

**Q: スケジュールが表示されない**
- HTML要素のIDが正しいか確認
- コンソールエラーをチェック

**Q: 週の計算がずれる**
- `getWeekOfMonth()`関数は月の最初の該当曜日から計算します
- 例: 5月1日が金曜なら、5月1日=第1週、5月8日=第2週

**Q: 偶数月/奇数月が逆になる**
- 1月=1（奇数）、2月=2（偶数）で計算されます
